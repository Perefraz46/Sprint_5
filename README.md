# Sprint_5
Stellar Burgers Autotests
Проект автоматизированного тестирования для сервиса Stellar Burgers (космический фастфуд). Набор тестов проверяет основные функции веб-приложения.

Структура проекта
1. Основные файлы
urls.py
Содержит URL-адреса приложения
2. locators.py
Содержит локаторы элементов страницы, сгруппированные по функциональности
3. test_data.py
Тестовые данные
4. conftest.py
Фикстуры pytest
5. Папка tests с тестовыми файлами:

test_registration.py - Тестирует регистрацию пользователя:
* Регистрация с валидными данными
* Регистрация без имени
* Регистрация с коротким паролем

test_login.py - Тестирует вход в систему:
* Вход с главной страницы
* Вход через личный кабинет
* Вход со страницы регистрации
* Вход со страницы восстановления пароля

test_logout.py - Тестирует выход из системы:
* Выход через кнопку в личном кабинете

test_profile.py - Тестирует доступ к профилю:
* Доступ авторизованного пользователя
* Перенаправление неавторизованного пользователя

test_constructor.py - Тестирует конструктор бургеров:
* Переключение между разделами (Булки, Соусы, Начинки)
* Проверка активного раздела

Структура тестов
Каждый тестовый класс содержит:
* Подготовительные действия (переход на страницу)
* Заполнение полей формы
* Выполнение действия (клик, отправка формы)
* Проверки результата (assert)

Тесты используют:
* Явные ожидания (WebDriverWait)
* Параметризацию для тестирования разных сценариев
* Фикстуры для инициализации браузера
